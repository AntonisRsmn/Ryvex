

# 🚀 Ryvex Update — v1.10.2

Hello everyone! 👋  
**Ryvex v1.10.2** is here with a major new feature and polish for your server!

---

## 🎉 What's New

### 🎂 Birthday & Anniversary System
- New `/birthday` user command: set, view, and check today's birthdays
- New `/admin-birthday` admin command: enable/disable, set channel, set/reset custom message, view config
- Daily birthday announcements with random or custom messages
- Per-guild config: enable/disable, channel, message, reset

---

### 🖌️ Modern Embed Restyle
- All embeds now use a consistent, branded look for a polished experience

---

### 🛡️ Reliability & Bug Fixes
- Fixed all ephemeral: true deprecation warnings (now uses MessageFlags.Ephemeral)
- Fixed JSON parse errors for empty/corrupt files
- Fixed double reply/deferReply issues in `/botinfo`
- General polish and error-proofing

---
